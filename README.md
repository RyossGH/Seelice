Seelice (prononcez « silice »)

Seelice centralise toutes les caméras IP d’un réseau dans une seule interface web, quelle que soit leur marque. On branche les caméras, Seelice les détecte, et tout se pilote depuis un navigateur : mosaïque en direct, plein écran HD, captures, statut en temps réel.

Pensé par des techniciens réseau, Seelice met l’accent sur une installation propre et sécurisée : caméras isolées dans leur VLAN, aucun port ouvert sur Internet, accès protégé.

La silice, c’est le verre des objectifs et des fibres optiques. Seelice, c’est voir clair sur tout votre réseau.
